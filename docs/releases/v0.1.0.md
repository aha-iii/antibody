# Nerve Antibody v0.1.0

**发布日期**：2026-11-12  
**仓库**：`nerve/nerve-waf-native/nerve-antibody`  
**配套版本**：Nerve WAF `v1.0.0`（宿主，可选 `expert` feature 同进程调用）

---

首个开源发布版本。Nerve Antibody（Arc-Cortex）是 Nerve WAF 的检测引擎子产品，独立发版，
引擎与规则包节奏解耦。本版作为对外基线，同时修掉了改名遗留的依赖断链与一处高频误报。

## 本版重点

**1. 引擎能力基线**

| 能力 | 说明 |
|------|------|
| 规则语言 | `when.all/any`、`transforms`、`block`/`observe`/`allow`、`min_level` |
| 三档烈度 | Low / Medium / High 独立 `Program` + `threshold_by_level` |
| 编译器 | DSL → `Program` / Artifact；contains 字典 + 倒排索引 |
| 运行时 | Aho-Corasick 预过滤、`FieldCache`、评分融合 |
| L2 语义 | SQL / XSS / Path 启发式 + veto |
| L3 自适应 | 浅特征加分，不可单独拦截 |
| 加速 | 默认 `aho-corasick`；Hyperscan 经 feature 可选 |
| 热更新 | 内容哈希 + 可选 HMAC，`Engine::reload` |

**2. 开源合规**

`LICENSE`（MIT）+ `SECURITY.md` + `CONTRIBUTING.md` + `rust-toolchain.toml` + `Makefile` + `install.sh`。
`Cargo.toml` 的 `license` 由 `"proprietary"` 改为 `"MIT"`。

**3. 修复改名遗留的编译阻塞**

4 个 crate 的 path 依赖仍指向改名前的 `Nerve-defender/`，而实际目录已是 `Nerve-waf/`，
`cargo build` 无法解析 workspace。受影响：`nerve-antibody-dsl`、`-engine`、`-pipeline`、`-runtime`
（另含 `-dashboard` 对 `nerve-waf-auth` 的引用）。

**4. 修掉 Authorization 侧信道误报**

JWT 签名是高熵 base64，与 `ognl`、`awk` 这类短针会发生偶然子串碰撞，导致带合法 Bearer token 的
登录请求被误判。本版新增 `is_bearer_jwt_authorization()`，标准三/五段 JWT/JWE（含裸 `eyJ` 开头）
不再进侧信道解码；非 JWT 的 Authorization（Basic、裸注入载荷）仍正常检测，JWT 结构异常交给专用 header 规则。
同时把 `ognl`、`awk` 改为词边界正则并设 `scope: raw`。

**5. 规则包 baseline 推进至 1.5.63**

| 版本 | 规则 | 类型 |
|------|------|------|
| 1.5.60 | `nextjs-rsc-flight-rce` | 新增：Next.js RSC/Flight RCE 探测 |
| 1.5.61 | `webshell-php-path-probe` | 新增：扫描器 PHP 短路径探针；同时收窄原「任意 `.php` 即命中」 |
| 1.5.62 | `java-struts-redirect-ognl` / `jwt-auth-core-anomaly` | 修正：裸串改词边界 regex + `scope: raw` |
| 1.5.63 | `authz-header-injection` | 新增：Authorization 头注入（OGNL/awk/SQLi/壳元字符） |

每条新规则都配套正/负样本，位于 `packs/baseline/samples/`。规则包独立变更历史见
[`packs/baseline/CHANGELOG.md`](../../packs/baseline/CHANGELOG.md)。

## 安装前提

本仓库与 `Nerve-waf` 通过相对路径互相依赖，**必须保持同级目录**，单独 clone 无法完成 workspace 解析：

```text
<workspace>/
├── Nerve-waf/
└── Nerve-antibody/
```

```bash
cd Nerve-antibody
bash install.sh              # 依赖自检 + release 构建 + 跑测试
bash install.sh --skip-test  # 只构建
```

等价 Make 目标：`make install` / `make build` / `make test` / `make fmt` / `make clippy`（`make help` 查看全部）。
